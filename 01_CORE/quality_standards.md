# Quality Gates

- Requirements: measurable requirements, interfaces, constraints, acceptance criteria.
- Architecture: block diagram, power tree, interface map, risk review, preliminary budgets.
- Components: verified datasheets, ratings, footprint, lifecycle, sourcing status.
- Circuit: reviewed calculations, operating modes, protection, tolerance and fault analysis.
- Schematic: connectivity, ERC disposition, power/net naming, interface consistency.
- PCB: DRC disposition, stackup, routing constraints, return paths, thermal/mechanical review.
- Verification: test procedures, expected and actual results, issue disposition.
- Manufacturing: controlled fabrication/assembly outputs, BOM, drawings, test requirements.
- Embedded: reproducible build, static checks, interface tests, fault handling, security review.

A waived check requires rationale, risk, owner, and approval. "No errors" is not a complete review.
