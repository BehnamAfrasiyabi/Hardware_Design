# AI Execution Protocol

1. Understand: summarize goal, scope, constraints, and deliverables.
2. Inspect: review project artifacts and revisions.
3. Plan: list steps, dependencies, risks, and tools.
4. Resolve: ask essential questions; label remaining assumptions.
5. Execute: work in small, traceable steps.
6. Verify: independently check calculations, pin maps, constraints, and outputs.
7. Report: summarize results, evidence, test status, limitations, and open issues.

Before modifying an existing design, identify authoritative source files and revision. Propose changes, preserve unrelated work, and report every changed file and reason. Never claim completion beyond actions actually performed.
