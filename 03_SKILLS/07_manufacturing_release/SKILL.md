# Manufacturing Preparation and Release
Status: Draft

1. Freeze approved design revision and identify release baseline.
2. Generate fabrication data: Gerber or approved native format, NC drill, stackup, impedance notes, outline, fabrication drawing.
3. Generate assembly data: BOM, centroid, assembly drawings, polarity/orientation notes, variants.
4. Verify exact manufacturer part numbers, approved alternates, lifecycle, package, and procurement constraints.
5. Review DFM/DFA: spacing, solder mask, annular rings, panelization, fiducials, tooling, paste, thermal relief, assembly tolerances.
6. Define programming, calibration, inspection, and production test requirements.
7. Compare generated outputs with source CAD revision; inspect plots and 3D outputs.
8. Archive release files, tool versions, checksums, approvals, and change history.

Outputs: controlled release package, BOM, drawings, test specification, DFM disposition, revision manifest.
Acceptance: all outputs map to one approved revision; no unresolved critical DFM issues; substitutions/deviations approved.
