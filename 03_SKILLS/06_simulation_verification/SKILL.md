# Simulation and Verification
Status: Draft

1. Define the question the simulation or test must answer.
2. Select model, solver, instrument, and method; state limitations.
3. Record tool version, model source/version, setup, boundary conditions, and parameters.
4. Include parasitics, tolerances, temperature, loads, and initial conditions where material.
5. Define expected behavior and quantitative pass/fail criteria before execution.
6. Preserve raw outputs, logs, plots, and configuration.
7. Compare results with hand calculations and datasheet limits.
8. For physical tests record calibration, fixtures, probes, bandwidth, uncertainty, safety precautions, and observations.
9. Track failures, root cause, corrective action, and regression tests.

Outputs: plan, configuration, predicted/measured results, deviations, limitations, disposition.
Acceptance: simulation is not called a physical test; planned tests are not reported passed; results are reproducible.
