# Altium Schematic Design and Review
Status: Draft

1. Confirm Altium Designer version, project conventions, libraries, and authoritative source files.
2. Verify symbols, pin numbers/types, hidden pins, footprints, and manufacturer links against datasheets.
3. Organize sheets by functional blocks with readable signal flow.
4. Apply consistent net naming, power ports, hierarchy, designators, and annotations.
5. Review power domains, reset/boot straps, clocks, programming/debug, connectors, and test points.
6. Run ERC; review every error and warning and document justified exceptions.
7. Cross-check connectivity and critical pin mapping against datasheets.
8. Record library provenance and revision.

Outputs: schematic sources, library linkage report, ERC disposition, pin-map review, open issues.
Acceptance: no unexplained ERC findings or unverified pin mapping. Never claim Altium checks ran unless they did.
