# PCB Design and Layout
Status: Draft

1. Confirm outline, mechanical constraints, connectors, mounting, keepouts, and assembly process.
2. Define stackup with fabricator capability, material properties, copper weights, and impedance needs.
3. Set placement priorities, critical loops, partitioning, thermal paths, and service access.
4. Define net classes and constraints for current, width, clearance, differential pairs, length, impedance, vias, and return paths.
5. Route power and sensitive/high-speed nets with appropriate topology and continuous return paths.
6. Review decoupling and switching loops, grounding, via transitions, and reference planes.
7. Check thermal relief, copper balance, solder mask, silkscreen, creepage/clearance, edge clearance, and panelization.
8. Run DRC; inspect exceptions, 3D/mechanical fit, and fabrication constraints.
9. Review test access, programming, probing, and rework.

Outputs: stackup, constraints, routing rationale, DRC disposition, mechanical/thermal/SI/PI review as applicable, fabrication notes.
Acceptance: no unexplained DRC violations; stackup and impedance assumptions agreed with fabricator; critical return paths and clearances reviewed.
