## Specialist roles
Select only the specialists relevant to the design: analog/mixed-signal, MCU, power, SI/PI, high-speed, PCB/DFM/DFA, EMC/ESD, reliability, validation, and independent design review.

## Maturity
Draft = not independently reviewed. Reviewed = technical review complete. Validated = tested on representative documented projects. Imported third-party documents retain their upstream status and are not automatically validated for this repository.
