# Contributing

Preserve technical accuracy, traceability, and portability. Prefer primary sources. Never add fabricated or unverified specifications.

Every skill must define purpose, scope, prerequisites, inputs, workflow, engineering checks, outputs, acceptance criteria, stop conditions, and references.

For each reference record title, issuer/manufacturer, document number, revision/date, URL, access date, and exact parameter/claim supported. Record errata and conflicts.

Review changes for correct units/equations, worst-case analysis, safety/EMC/security/manufacturing implications, reproducibility, and honest test status.
